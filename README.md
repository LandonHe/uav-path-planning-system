# 风扰环境下城市低空无人机路径规划系统

《风扰环境下城市低空无人机路径规划研究》大创课题的交互式仿真平台。
输入环境、无人机、任务参数，即可自动规划并对比多条考虑风扰的飞行路径，
支持 2D/3D 查看、在线地图导入真实建筑、图像自动识别建筑、禁飞区、
空域分析与路径合理性检验。

## 快速开始

1. 下载本仓库，用 **Chrome / Edge** 打开 `index.html`（双击即可，无需安装）。
2. 按四个步骤操作：
   - ① 环境参数：风场类型 / 风速风向 / 空域范围 / 障碍物（示例、导入、在线地图、卫星图自动识别、自定义）；
   - ② 无人机：优化目标（效率/效益/安全/平衡）→ 自动推荐机型并显示完整参数；
   - ③ 空域建模：栅格分辨率 / 飞行高度 / 禁飞区 / 高度层切片 / 风风险热力图 / 可飞性分析；
   - ④ 路径规划：四种算法对比（风感知 A*、传统 A*、RRT*、PSO）、指标对比、路径合理性检验。

## 功能特性

- 风场模型：均匀风 / 阵风 / 湍流（Dryden）/ 建筑尾流 / 复合风，含幂律风廓线、垂直风；
- 风感知代价：时间 + 能耗 + 风风险 + 转弯惩罚；地速 = 空速 ± 风速分量；
- 算法对比：风感知 A*（本文方法）、传统 A*（无风基线）、RRT*、PSO；
- 轨迹平滑：B 样条 / Minimum Snap，含转弯半径与加速度检验；
- 多机协同：2–4 架无人机路径规划、冲突检测与时间错开、飞行回放；
- 在线地图：搜索地区（OSM/高德）→ 拉取真实建筑自动生成障碍物；
- 卫星图分析：导入截图后自动识别建筑（深色/浅色双模式）；
- 安全约束：机型抗风上限 / 载重 / 悬停能力校验，不可飞区域硬性拦截；
- 机型库：7 种内置机型（含重载/安防巡检/长航时测绘）+ 自定义机型录入，按真实参数参与选型、安全校验与规划；
- 方案保存：所有参数自动保存/恢复，支持导出/导入 .json 方案文件；
- 空域分析：高度层切片、风风险热力图、可飞性分析（绿=可飞，红=不可飞）；
- 路径合理性检验：飞行高度范围、层风速裕度、续航、最小净空等逐项对照。

## 说明

- 机型能耗、抗风上限、推荐高度范围等为**示例预设**，正式研究请按实际机型标定；
- 在线地图功能需要联网；OSM 部分地区建筑高度数据不全，按层数×3.5m 或默认值估算；
